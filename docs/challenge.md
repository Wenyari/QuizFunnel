前端挑战 · 健康测评获客漏斗（Quiz Funnel）
在你开始之前
我们想看的不是你能不能"跑起来"一个问卷，而是——你能不能做出一个让用户愿意一路点到底的问卷。
UI 的丝滑感、逻辑的闭环、以及你和 AI 的协作效率，是我们最关心的三件事。

一、参考竞品
请先体验一下这个产品再开始动手——它是这个赛道里做得最成熟的样本之一，也是你这次任务的主要参考对象：
🔗 BetterMe Quiz Funnel：https://betterme-pilates.com/first-page-brand-palette?flow=2117
我们不要求你 1:1 复刻，但希望你认真体验它的节奏感、动效、信息密度和交付感，并在自己的实现里做出你认为更好的判断。

二、任务目标
用 Next.js 开发一个健康测评问卷。我们看重的是：
●UI 审美：丝滑感、动效细节、欧美主流 App 的高级感
●逻辑闭环：从入口到付费，每一步都站得住
●AI 协作能力：你怎么调教 AI 高效产出高质量代码

三、核心流程（必须严格遵守）
第一阶段 · 收集信息（Step 1–3）
Step 1：基础信息
●选择性别（男 / 女）
●选择健身目标（减脂 / 增肌 / 塑形）
Step 2：身体数据
●必须支持公制 / 英制切换
●字段：年龄、身高、体重、目标体重
●需有基础输入校验
Step 3：运动频率
●选择当前运动频率
第二阶段 · 分析中（Step 4）
Step 4：强制等待 3.5 秒
●全屏动画
●动态进度条
●轮播文案（如："正在分析您的 BMI..."）
第三阶段 · 结果与付费（Step 5）
Step 5：生成报告页
●根据 Step 2 数据动态显示预测结果（如：预计达标日期）
●展示一个简单的体重变化趋势图
●点击按钮弹出订阅价格卡片

四、技术要求
●框架：Next.js（App Router） + TypeScript + Tailwind CSS
●动效：Framer Motion 或 GSAP（步骤切换必须有丝滑动画）
●状态管理：Zustand 或 React Context（刷新页面数据不丢失）
●部署：Vercel 或 Netlify

五、交付物
1.代码仓库：GitHub 链接
2.在线预览地址：必须适配移动端
3.AI 使用说明：简述你用了什么 AI 工具、哪些代码是 AI 写的、哪些是你手动优化的

六、评分标准
好看吗？ UI 是否达到欧美主流 App 的高级感——间距、字体、动效、视觉层级。
稳健吗？ 路由跳转、数据计算、页面刷新后状态恢复，是否都正常工作。
快吗？ 你利用 AI 的程度如何？代码结构是否清晰可复用？是不是只把 AI 当代码生成器，还是真的在和它协作？
