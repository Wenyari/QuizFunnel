# Module 5: 假加载与情绪铺垫模块 (Fake Analysis)

## 详细设计
这是提升漏斗转化率（用户信任度）的关键环节（对应 Step 4）。页面不接收用户输入，纯通过动画、进度条和不断切换的文案，营造出“正在由强大的 AI 分析身体数据”的错觉，最后自动跳转到结果页。

- **Loading视图 (`app/quiz/[step]/page.tsx` 中拦截处理)**: 一个全屏的加载状态。
- **全屏动画与进度条**: 使用 Framer Motion 处理耗时 3.5 秒从 0% 涨到 100% 的进度条。
- **文案轮播器**: 使用 React `useState` 和 `setInterval` 定时切换分析文案。
