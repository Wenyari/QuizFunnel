# Module 6: 结果预测与可视化模块 (Result & Paywall)

## 详细设计
本模块（对应 Step 5）负责展示最终极具吸引力的计算结果和付费墙卡片。核心是通过 D3.js 绘制一条极其平滑且带有阴影渐变的体重下降/上升趋势曲线，激发用户付费意愿。

- **数据集成**: 提取 Store 数据，调用 `utils/calculation.ts` 得到初始值与目标值及达成时间。
- **TrendChart (`components/quiz/TrendChart.tsx`)**: 基于 D3.js，接收 React 传入的点位坐标进行 SVG 绘制。
- **Subscription Card**: 包含价格、卖点和呼吸灯 CTA 按钮的悬浮卡片。
