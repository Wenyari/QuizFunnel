# Module 4: 问卷业务逻辑 (Steps 1-3)

## 详细设计
基于前三个模块，正式实现用户实际交互的问卷页面。重点在于表单输入、Zod 校验接入，以及多字段联动的复杂交互（如 Step 2 的公制/英制切换）。

- **StepLayout (`components/quiz/StepLayout.tsx`)**: 为各步骤提供一致的标题、说明布局。
- **Step 1 (选项卡)**: 性别和目标的单选，点击后自动或手动进入下一步。
- **Step 2 (身体数据录入)**: 复杂表单，包含单位切换，以及年龄、身高、体重的数值输入。
- **Step 3 (运动频率)**: 单选列表。
