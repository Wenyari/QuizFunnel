# 项目骨架搭建总结

本文档记录了基于《项目设计文档》完成的初始骨架搭建工作与生成的目录结构。此骨架不包含具体的业务逻辑，仅作为后续开发的入口。

## 1. 基础环境与配置初始化

*   **框架初始化**：使用 `npx create-next-app` 初始化了 Next.js 14 项目（App Router，TypeScript，Tailwind CSS）。
*   **目录层级调整**：移除了默认的 `src` 目录，将 `app` 移至根目录，并在 `tsconfig.json` 中更新了 `@/*` 的路径映射（指向 `./*`），以严格遵守设计文档中的扁平化目录规范。

## 2. 核心依赖安装

除了 Next.js 自带的依赖外，额外安装了设计文档中规划的核心第三方库：
*   状态管理：`zustand`
*   动画与交互：`framer-motion`
*   数据可视化：`d3` 及 `@types/d3`
*   数据校验：`zod`
*   样式合并工具：`clsx`, `tailwind-merge`

## 3. 创建的核心目录与占位文件

按照设计文档的设计，已在项目中创建以下空占位文件，以便于后续模块化开发：

### 路由模块 (Quiz Engine)
*   `app/quiz/layout.tsx`：问卷核心路由的过渡布局（后续将接入 Framer Motion 的 `AnimatePresence`）。
*   `app/quiz/[step]/page.tsx`：动态路由页面，用于承载问卷的 Step 1 - 5。

### 状态与配置 (Store & Config)
*   `store/useQuizStore.ts`：Zustand 状态管理的入口。
*   `config/quizFlow.ts`：配置驱动问卷的流转配置表。

### UI 原子组件层 (Atomic UI)
*   `components/ui/Button.tsx`：基础按钮组件。
*   `components/ui/Card.tsx`：基础卡片组件。
*   `components/ui/Input.tsx`：基础输入框组件。
*   `components/ui/ProgressBar.tsx`：基础进度条组件。

### 业务组件层 (Feature Components)
*   `components/quiz/StepLayout.tsx`：包含标题、副标题的单步通用布局。
*   `components/quiz/OptionList.tsx`：选择题列表组件。
*   `components/quiz/TrendChart.tsx`：D3.js 驱动的趋势图组件。

### 纯函数与工具层 (Utils)
*   `utils/calculation.ts`：用于 BMI、目标日期预测等纯逻辑计算。
*   `utils/validation.ts`：存放基于 Zod 的 Schema 数据校验逻辑。

---
**后续开发建议**：
可以以此结构为基础，按职责分批生成代码，例如优先完善 `config/quizFlow.ts` 和 `store/useQuizStore.ts`，再逐步填充 `components/ui/` 下的原子组件。
